# 📚 BookStore Web Application

An elegant and modern online Book Store where users can browse, add to cart, and securely checkout books using online payment.

## 🚀 Features

- 🛒 Browse books
- 📖 View book details
- 🧺 Shopping cart system
- 💳 Stripe payment integration
- 🔐 Secure authentication system 
- 📦 Order management for customers
- 📊 Admin dashboard to manage books and orders and Categories  and Users
- 📁 Clean N-Tier architecture 
- 🌐 Responsive UI built with Bootstrap

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, Bootstrap, JavaScript
- **Backend:** ASP.NET Core MVC
- **Database:** SQL Server
- **ORM:** Entity Framework Core
- **Authentication:** Identity 
- **Payment:** Stripe API
- **Architecture:** N-Tier 
- **Version Control:** Git & GitHub
